# Pilot Flow — Backend

Backend: **ASP.NET Core / C#, PostgreSQL**. Соседний репозиторий: [frontend](https://github.com/SwagaTeam/pilot-flow-frontend).

Это готовые контракты и схема для начала реализации; ASP.NET приложение ещё не написано.

## Запуск и материалы

- `schema.sql`: применить один раз к пустой БД: `psql -v ON_ERROR_STOP=1 -d pilot_db -f schema.sql`.
- `handoff.html`: правила, архитектура, спорные требования и распределение работ.
- `openapi.yaml` / `openapi.json`: контракт 1.0.0, 45 операций, 51 схема.
- `swagger.html`: открыть локально вместе с CSS/JS из этого репозитория.
- `control-example.json`, `acceptance-vectors.json`: эталонные данные и граничные случаи.
- `validation-report.json`: результаты проверки схемы и контракта.
- `pilot-flow-contract-v1.zip`: полный первоначальный пакет.

## Ответственность backend

Реализовать DTO и endpoints по OpenAPI; хранение и миграции; расчёт допуска и рейтинга; проверку полноты; ETag/If-Match; авторизацию владельца; неизменяемые снимки решения; PDF-экспорт. Детали в `handoff.html`.

## Единый контракт

Авторитетная версия OpenAPI хранится здесь. Frontend содержит побайтовую копию версии 1.0.0. Любые изменения контракта выпускаются согласованно в обоих репозиториях до изменения клиентов. Не менять значения enum, nullable и decimal-строки независимо.

Проверены 313 примеров API и 19 проверок БД (PGlite). Производственный ASP.NET сервер ещё не тестировался.
