# Семейства, оценка и фиксация решения

Ветка `main`. HTTP-слой использует контроллеры по ресурсам и существующие ETag агрегата.

- [ ] Реализовать семейства, маршруты, перенос продукции и редактор показателей. Покрыть инвалидацию и конфликты записи.
- [ ] Реализовать расчёт допуска, баллов, матриц и проверку выбора. Сверить результаты с контрольным примером.
- [ ] Реализовать реквизиты, выбор, предварительный просмотр, транзакционную фиксацию и чтение сохранённого снимка.
- [ ] Реализовать PDF и создание нового черновика из зафиксированной версии.
- [ ] Проверить контракт, полную цепочку на PostgreSQL и запуск Docker. Отправить проверенные коммиты в `origin/main`.
